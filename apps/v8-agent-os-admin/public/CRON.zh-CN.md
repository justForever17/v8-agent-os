# 定时任务配置指南

定时任务允许 V8 Agent OS 在后台按固定时间自动执行任务。

## Cron 表达式基础

Cron 表达式共有 5 位，顺序为：**`分 时 日 月 周`**。

| 位置 | 含义 | 允许值 | 示例 |
| :--- | :--- | :--- | :--- |
| 第 1 位 | 分钟 | `0-59` | `0,30` |
| 第 2 位 | 小时 | `0-23` | `8-10` |
| 第 3 位 | 日期 | `1-31` | `*/2` |
| 第 4 位 | 月份 | `1-12` | `*` |
| 第 5 位 | 星期 | `0-7`（0 和 7 都是周日） | `1-5` |

如果你不熟悉表达式，优先用表单里的预设时间。

## 执行类型

### 系统命令

直接调用系统命令或可执行文件。

示例：

```text
node dist/index.js
```

### Python 脚本

在 Engine Python 环境中执行指定脚本。

示例：

```text
scripts/cron_nightly_memory_batch.py
```

### AutomationRuntime 任务

把任务交给 AutomationRuntime 执行。

示例：

```text
supervisor
```

## 使用建议

- 高风险任务先降低频率，再观察日志
- 长耗时任务避免设置得过于频繁
- 需要结构化参数时，用 JSON 填写附加参数
- 先验证一次“立即运行”，再长期启用

## 排查方向

- Cron 表达式是否正确
- 执行目标是否可独立运行
- 参数 JSON 是否合法
- 执行日志里是否有超时或异常
