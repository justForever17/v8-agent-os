V8OS 消息界面设计标准

设计语言：编辑器式工具界面

界面像可靠的工作台，而不是展示型 AI 落地页。视觉层级来自排版、间距和细分隔线；圆角、底色和动效只负责表达边界与状态。

核心规则

  • 助手正文不套气泡；用户消息仅使用一个中性、低对比的 6px 小圆角容器。
  • 思考与工具调用是可展开的执行摘要，不重复制造 Runtime 状态卡。
  • 文件和产物在消息里只保留紧凑索引；Web 在 Workbench 打开，Phone 使用近全屏专用视图。
  • Workbench 默认约占内容区三分之一，消息区约三分之二，中线可拖拽，关闭后完全卸载。
  • 错误、风险、等待用户确认使用语义色和左边界，不使用大色块警告卡。

组件 Token

对象标准目的
圆角2 / 4 / 6 / 8px表达结构，不营造软糖感
Tab34px接近代码编辑器密度
工具栏32–40px减少无意义标题横框
边框1px hairline替代阴影和嵌套卡片
正文13px / 1.7长对话可读且不松散
Phone 触控至少 44px不把 Web 密度机械缩小

禁止模式

  • 渐变紫、发光、玻璃拟态、重阴影和大面积品牌色。
  • 大圆角卡片套大圆角卡片；大标题横框；每个事件单独占一张卡。
  • 把思考、工具日志、Runtime 卡和最终答案重复展示三遍。
  • Phone 直接缩放桌面 Workbench，或让无限事件列表在后台持续重渲染。
