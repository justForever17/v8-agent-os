## 二、 关键路径首屏拆解与确定性指标

根据 `huashu-flash` 要求，我们梳理确定性可数的代理指标（每次构建/运行均为确定性数值，与体感强相关）：

### 1. 构建期确定性指标（代理指标）
- **Initial JS Bundle Size**：首屏加载所需关键 JavaScript 字节数；
- **Mermaid 包含状态**：首屏主入口 Chunk 中 `mermaid` 模块是否为 0 字节（必须从首屏剥离，变为按需加载）；
- **Prism 包含状态**：首屏主入口中语法高亮全量包是否为 0 字节；
- **Lucide 图标包树摇效率**：是否仅打入实际使用的小图标。

### 2. 运行期确定性指标
- **每次 Token 变化的主线程正则执行次数与耗时**：从全文 5 次带回溯正则降为增量/分块缓存；
- **Admin 单次路由切换网络请求数**：从 10 个并发收敛为带前置命中内存缓存的秒级呈现；
- **Electron Shell 水合就绪耗时（TTI）**：从导航到 `inputHitTestReady === true` 的间隔。

## 三、 下一步专项优化招式清单（照 Anthropic 招式库）

1. **招式一：首屏剥离 Mermaid 与代码高亮（重型库按需加载）**
   - 将 `CodeBlock.tsx` 中的 `MermaidRenderer` 改为按需动态加载；
   - 语法高亮采用分块加载（非关键路径异步着色，首屏纯文本秒出）；
   - **预期收益**：首屏初始 JS Bundle 减少 1.5MB~3MB，页面秒开。

2. **招式二：Next.js 配置编译级包导入优化（optimizePackageImports）**
   - 在 `next.config.ts` 中配置：
     ```ts
     experimental: {
       externalDir: true,
       optimizePackageImports: ["lucide-react", "@lobehub/icons-static-svg", "recharts", "framer-motion"],
     }
     ```
   - **预期收益**：极大缩短 AST 编译和打包体积，减少无效导出解析。

3. **招式三：流式 Markdown 增量渲染与正则优化（长内容渲染）**
   - 优化 `preprocessContent` 中的复杂回溯正则，避免对全文重复进行昂贵的大文本匹配；
   - 对已完成的聊天 Turn 节点实施 Memoization 缓存，流式阶段仅让当前活动的最后一条消息重算。

4. **招式四：Admin 预取与并发请求聚合并行化**
   - 保持现有鉴权安全的前提下，对高频重合请求（如 `/api/admin/models`）优化内存命中率；
   - 对 `recharts` 实施 `next/dynamic` 懒加载。

5. **招式五：Phone 端端点探测并行竞速（Fast-Fail Race）**
   - 优化候选端点轮询，优先使用本地 LAN 或最近成功端点，短超时并发探测，消除冷启等待。
