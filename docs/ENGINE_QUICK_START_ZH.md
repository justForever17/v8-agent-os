# V8 Agent OS - 快速入门指南

欢迎使用 **V8 Agent OS**。如果你厌倦了一次又一次与聊天助手重复讲述来龙去脉、受够了无法随时干预的“黑盒”智能体执行，那么你来对地方了。这是一个具备全局视野记忆、可观测甚至可中断审批的运行时（Runtime）机器生态。

这篇指南能让你（或者你的团队新成员）看一眼后，花极少的时间快速把这架机器在本地冷启动跑起来。

## 1. 系统角色分布 (你需要知道哪几层)

系统启动后会在不同的服务端口负责不同的工作面貌：
- **Web (默认端口: `9527`)**: 呈现给用户的客户端面貌，包括聊天历史气泡、Timeline 观测图等等。
- **Admin (默认端口: `9528`)**: 控制面也是监控中心。这相当于机器的仪表盘，用来配置各种复杂设定的（比如装什么 MCP 技能、换什么模型）。
- **Engine (默认端口: `9530`)**: 最底层也是最重要的发动机引擎端。长文本理解、插件的调用触发、各种图和流程中转判定其实全部发生在这里。

## 2. 如何一行命令启动

不要手动去启动每个项目的 npm 包依赖安装。在根仓库目录，系统官方提供好了傻瓜式入口指令。

### Windows 系统
使用 PowerShell 执行以下命令：
```powershell
powershell -ExecutionPolicy Bypass -File .\bootstrap.ps1
```
*(如果没有代码库本体，也可使用线上拉取装载 `powershell -ExecutionPolicy Bypass -Command "irm https://raw.githubusercontent.com/justForever17/v8-agent-os/main/bootstrap.ps1 | iex"`)*

### macOS / Linux 平台
使用终端 Bash 运行：
```bash
./bootstrap.sh
```

*(上述命令会自动处理环境依赖以及后台拉起需要同时运作的服务，首次启动由于要下发依赖耗时稍久，请耐心等待。)*

## 3. 初始调教配置（必看顺序）

安装脚本并启动成功后，不要一上来就打开前端聊天界面发起沟通。

1. **第一步，打开 Admin 面板**：浏览器直接访问 `http://127.0.0.1:9528`。
2. **第二步，基础连通必配置项**：
   - 寻找 **Models（模型设定区）**，务必配置主用的推理基座大语言模型。
   - **重点强调：** 强烈建议将 Reranker 选项配置完善，没有 Reranker 系统的记忆抽取召回准确率会有悬崖式的崩塌。
3. **第三步，技能生态对接**：
   根据你需要的工作，比如读取本地系统代码还是连接外部 Web Server，通过 MCP 将你的依赖加载上。
4. **最后，打开 Web 端**：确认以上两步保存无误，访问 `http://127.0.0.1:9527` 即可开始真正享受 V8 Agent OS 带来的沉浸式多模协同与开发工作流。

## 4. 给入门新手的几个“少踩坑”法则

- **唯一定位配置真相**：在任何需要手工确认或修改后台配置参数的地方，直接前往你的系统目录下的 `~/.v8-agent-os/config.json` 即可。所有的基础定义和环境选项都收拢于这条主干，不需要翻找其他文件。
- **看报错找根源发源地**：如果界面出现奇怪响应，不要死盯着 9527 页面看 Network 接口错漏。往往最全面最翔实且原汁原味的链路报错会在后台被 Engine（9530端口）所在的 Terminal 终端打出来。
- **不要为了省事砍掉“审批机制 (Approvals)”**：当发现系统请求向本地某些重要目录发起删除请求被卡住的时候，这不是 Bug。利用 Admin 后台或交互界面的 Resume 发出同意。审批流长任务的核心特征。
