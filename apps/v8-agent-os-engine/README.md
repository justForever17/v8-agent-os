# This is V8 Agent OS Engine.
#
# It is the execution plane for runtimes, memory, automation, MCP, skills, safety, and recovery.
#
# Start here for local development:
#
# 1. `cd apps/v8-agent-os-engine`
# 2. `python -m venv .venv`
# 3. `.venv\\Scripts\\activate` on Windows, or `source .venv/bin/activate` on Linux/macOS
# 4. `python -m pip install -r requirements.txt`
# 5. `python main.py`
#
# Default local address: `http://127.0.0.1:9530`
#
# For the full system story, start from the repository root README and docs.
