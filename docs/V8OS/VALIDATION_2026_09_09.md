# 有序多图识别与 Supervisor 开发指导验收

基线：`9f10b0bc` / `v8-os-v2026.09.08.2`。日期：2026-09-09。

## 本轮范围

`vision_media_analyzer` 新增可选 `images` 列表，每项使用 `file_path` 或 `source_url`，可附 `label`。
列表与旧单输入参数互斥；通过逐图校验后，一次请求交错发送编号/标签与真实图片，保留重复图。
解析、权限与整组资源预检放在独立 helper；原有单图、视频和音频入口保留。

现阶段请求上限为 8 张静态图、32 MiB 原始与发送图片字节、40MP 原始像素总量。
沿既有图像归一化并记录缩放前后尺寸、源与发送内容 hash。这是请求资源边界，未增加模型输出 cap。
模型全文保留在工具结果；完整来源元数据留在受治理 observation，普通工具结果仅展示必要引用。
不登记重复产物，不逐图上传 S3，也不静默丢掉坏图后声称完整比较。

## 真实 provider 工具验证

使用开发机已经配置的 `volcengine-ark::doubao-seed-2-0-lite-260428` 视觉角色，无配置修改。
状态、图片和报告写入新隔离目录；ModelHub 配置只读入内存，未复制凭据。
视觉工具、路径预检、图像处理、factory 和模型调用是真实实现，只有配置读取重定向至现有模型域。

| 输入 | 行为结果 | 工具总耗时 | 输入 / 输出 token |
| --- | --- | --- | --- |
| 正向三图 | 左/中/右蓝圆，橙色块 1/2/3，对应编号均正确 | 14,939 ms | 4,313 / 546 |
| 同三图逆序 | 右/中/左，橙色块 3/2/1，未按标签猜原顺序 | 6,779 ms | 4,313 / 337 |
| 重复第一与第三图 | 右/左/右，橙色块 3/1/3，未去重丢编号 | 13,976 ms | 4,313 / 619 |

每组为一次模型请求，记录实际发送的三个图片 hash；均返回 `finish_reason=stop`。
回答区分静态可见变化与不能证明的操作因果。单次样本不证明普遍提速；未跑所有 provider。

复现入口（从 Engine 目录，参数目录必须尚不存在）：

```powershell
.venv/Scripts/python.exe tests/scripts/run_vision_images_live_audit.py --live --isolated-root <新隔离目录>
```

不带 `--live` 时，在导入 Engine、读配置、建状态或调用 provider 之前拒绝。
oracle 会拒绝逆序仍返回原顺序、缺少中间图、重复图被去重及截断 JSON。

三组实际 observation 已从隔离数据库只读回查：编号、发送图片 hash 和完整回答与 live 一致。
此检查已补入 harness，并用错 hash、空结果反例确认能报错；无需重新调用模型来检查已保存证据。

  范围覆盖有序图片、旧单图/音频、角色 schema、媒体资源权限、source ledger 与 live harness。

  同会话登记的外部上传/截图可精确读取，其他会话、错误工作区、已删除或改址登记及邻居文件不获授权。

  独立浏览器实际进入 `/chat`，新任务按钮可见可用，无 pageerror。实时连接使 `networkidle` 等待超时，
  因此用明确 UI 就绪条件完成检查；不把这一页面启动 smoke 说成多图聊天全链路验收。
- 17 个 V8OS Skill 加 2 个辅助 Skill 的结构/包一致性审计通过；36 场景覆盖审计通过。
  独立 Agent 做了人工审阅并补 validation/holdout 场景，修正“相同图换序必须改变结论”的过严判据。
  没有执行独立模型 Skill 行为评测，不标自动晋级或 holdout 行为成功。

## 指导与产品能力的区别

项目级 `v8os-supervisor-capabilities` 已接入总指挥路由，明确用户指定委派数量、身份、分工、
并行要求及禁止委派优先于默认直接执行。应用/媒体模型/浏览器观察的源码地图与设计目标分开。
更新工作区 AGENTS 和 action-kernel 多图事实，相关 `.skill` 分发包同步；这些文件位于主产品 Git 仓外。

Skill 是开发指导；本轮没有把跨 runtime 全部能力开放给 Supervisor，也没有新增产品 Planner、
权限注册表或任意直接调用路径。不能把结构审计或三组视觉工具 live 等同于 Supervisor 自主工具
选择、指定委派执行、真实桌面事件因果或所有平台验收。

## 兼容与回滚
